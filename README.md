# SHE Safety System (ระบบบริหารความปลอดภัยและตรวจสอบอุปกรณ์ดับเพลิง)

ระบบเว็บแอปพลิเคชันสำหรับตรวจสอบและบริหารจัดการอุปกรณ์ดับเพลิงและความปลอดภัยในการทำงาน (Safety, Health and Environment - SHE) พัฒนาด้วย **React 19 + TypeScript + Vite + Tailwind CSS** รองรับฐานข้อมูล **Cloudflare D1 (`d1shesystem`)** และที่เก็บไฟล์รูปภาพ **Cloudflare R2 (`r2shesystem`)** พร้อมรองรับการทำงานร่วมกับ **GitHub Desktop** ได้ทันที

---

## 📋 ฟังก์ชันและหน้าการทำงานของระบบ

### 1. หน้าเข้าสู่ระบบ (Login)
- หน้าแรกเมื่อเข้าสู่เว็บไซต์
- เข้าสู่ระบบด้วย **Username / Password**
- **"กดเพื่อเข้าเยี่ยมชม (Guest Mode)"**: เข้าชมข้อมูลเบื้องต้นแบบ Read-only โดยไม่ต้องกรอกรหัสผ่าน
- **"ลืมรหัสผ่าน"**: ส่งคำขอและการแจ้งเตือนไปยังแอดมิน เพื่อขอรีเซ็ทรหัสผ่านเป็น `0000`

### 2. หน้าสมัครสมาชิก (Register)
- กรอก Username, Password, และเลือก **Department (แผนก)** จาก Dropdown:
  - `พนักงาน` (ได้รับสิทธิ์เริ่มต้น P1)
  - `หัวหน้างาน` (ได้รับสิทธิ์เริ่มต้น P2)
  - `รองผู้จัดการ` (ได้รับสิทธิ์เริ่มต้น P2)
  - `ผู้จัดการ` (ได้รับสิทธิ์เริ่มต้น P2)
- เมื่อลงทะเบียนแล้ว ระบบจะกำหนดสถานะเป็น **รอแอดมินอนุมัติ (Pending Approval)**

### 3. หน้าจัดการสมาชิก (User Management) - สำหรับสิทธิ์ P3 และ P4
- แบ่งระดับสิทธิ์ตามมาตรฐาน SHE:
  - **P1 (พนักงาน)**: สามารถตรวจเช็คอุปกรณ์ได้เมื่อได้รับมอบหมายงานหรือได้รับอนุญาตจาก P2
  - **P2 (หัวหน้างาน, รองผู้จัดการ, ผู้จัดการ)**: สามารถตรวจเช็คอุปกรณ์ได้ทันทีไม่ต้องขออนุญาต และสามารถมอบหมายงานตรวจเช็คให้ P1 ได้
  - **P3 (แอดมิน)**: จัดการเพิ่ม/ลบพนักงาน, เลื่อนระดับสิทธิ์จาก P1 ไป P2, รีเซ็ทรหัสผ่านพนักงานเป็น `0000`, แก้ไขแผนกของผู้อื่น, อนุมัติสมาชิกใหม่, ส่งข้อความแจ้งเตือนไปยังผู้ใช้ที่เลือก
  - **P4 (ผู้จัดการระบบ / Super Admin)**: สิทธิ์สูงสุดในการบริหารจัดการระบบ

### 4. หน้าตรวจระบบอุปกรณ์ดับเพลิง (Fire Equipment Inspection)
แบ่งออกเป็น **4 แท็บ**:
1. **ถังดับเพลิง (EX)**: รันรหัส `EX-xxx` ต่อเนื่องอัตโนมัติ โดยเมื่อถังใดถูกลบหรือว่าง การเพิ่มใหม่จะนำเลขช่องว่างที่น้อยที่สุดมารันแทนที่ก่อนเสมอ พร้อมคำนวณอายุถัง (วันตรวจล่าสุด - วันเริ่มใช้งาน อิงเวลาไทย)
2. **ตู้ดับเพลิง (FHC)**
3. **ตู้สายฉีด (FH)**
4. **หัวรับน้ำดับเพลิง (HD)**

- แต่ละอุปกรณ์มี **Checklist เฉพาะทาง** ที่แตกต่างกัน
- **จำเป็นต้องแนบรูปภาพทุกครั้ง** (รูปใบตรวจเช็คคู่กับอุปกรณ์ และรูปสถานที่ติดตั้ง)
- **เมื่อพบข้อบกพร่อง/ผิดปกติ**:
  - ต้องแนบรูปจุดชำรุด พร้อมระบุคำอธิบายสาเหตุ
  - ระบบจะบันทึกสถานะเป็น `พบปัญหา (DEFECT)` และส่งการแจ้งเตือนไปยังแอดมินทันที
  - เมื่อได้รับการแก้ไขแล้ว สามารถกดบันทึกเป็น `แก้ไขแล้ว (RESOLVED)` และแสดงบนแดชบอร์ดให้เห็นได้ทันทีว่า **"มีปัญหาแต่ได้รับการแก้ไขแล้ว"**

### 5. หน้า Dashboard และรายงาน
- **สลับการนำเสนอข้อมูลได้**:
  - `อุปกรณ์ดับเพลิง`: แสดงสถิติการตรวจเช็ค ความพร้อมใช้งาน และข้อบกพร่อง
  - `Safety Committee (คปอ.)`: ข้อมูลสรุปกิจกรรม คปอ. (เตรียมพร้อมสำหรับอนาคต)
- **กราฟแท่งรายปี (Yearly Bar Chart)**: เปรียบเทียบสถิติการตรวจย้อนหลัง 3 ปี รวมปีปัจจุบัน อิงตามเวลาประเทศไทย (UTC+7)
- **กราฟวงกลมรายเดือน (Monthly Doughnut Chart)**: แสดงสัดส่วน พร้อมใช้ / ไม่พร้อมใช้ / พบปัญหา / แก้ไขแล้ว ในเดือนและปีที่เลือก
- **ระบบลบข้อมูลเก่าเกิน 3 ปีอัตโนมัติ**: ทำงานทุกวันที่ `01/01` ของปีปัจจุบัน (เวลาไทย)
- **ระบบรีเซ็ตรอบตรวจประจำเดือนอัตโนมัติ**: ปรับสถานะเป็น "ยังไม่ตรวจ" ทุกวันที่ 1 ของเดือน พร้อมส่งข้อความเตือนไปยัง P2, P3, P4
- **ปุ่ม Print Report สำหรับแอดมิน**:
  - ส่งออก **PDF** (รายเดือน / รายปี)
  - ส่งออก **Excel (.xlsx)** แยกแท็บตามประเภทอุปกรณ์
  - ส่งออก **รูปภาพ (.zip)** ทั้งหมดหรือเลือกตามรหัสอุปกรณ์

## 💻 วิธีการเปิดใช้งานและรันบนเครื่อง Local

1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```

2. เริ่มต้นรันโปรเจกต์ (Development Server):
   ```bash
   npm run dev
   ```

3. ทดสอบ Build โปรเจกต์:
   ```bash
   npm run build
   ```

## ☁️ การเชื่อมต่อ Cloudflare D1 (`d1shesystem`) และ R2 (`r2shesystem`)

### 1. การสร้างฐานข้อมูล Cloudflare D1
รันคำสั่ง Wrangler เพื่อสร้างฐานข้อมูล D1:
```bash
npx wrangler d1 create d1shesystem
```
เมื่อได้ `database_id` ให้นำมาอัปเดตในไฟล์ `wrangler.toml`

### 2. การรัน Schema ฐานข้อมูล D1
- **รันบนเครื่อง Local (จำลอง):**
  ```bash
  npm run d1:init:local
  ```
- **รันบน Cloudflare Production (Remote):**
  ```bash
  npm run d1:init:remote
  ```

### 3. การสร้าง Cloudflare R2 Bucket
รันคำสั่งสร้าง Bucket สำหรับจัดเก็บรูปภาพ:
```bash
npx wrangler r2 bucket create r2shesystem
```

### 4. Deploy ขึ้น Cloudflare Pages / Workers
```bash
npm run deploy
```
